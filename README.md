One short rant about a small everyday annoyance, written for a judge with a famously short temper. The rant is under 400 characters so the punch has to come fast. The program writes one deterministic text to `/output/entry.txt`; no clock, no random source and no network call reach the output.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node --experimental-strip-types main.ts
cat /tmp/out/entry.txt
```
